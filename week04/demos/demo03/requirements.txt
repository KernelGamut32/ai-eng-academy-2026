# Week 4 Demo 03: Verify and Repair
# The whole demo runs offline by default with a deterministic scripted model.
# No GPU, no model download, no network for the default path. It starts instantly.
#
# Verified by running the instructor notebook end to end in the build environment,
# entirely offline, on:
#   Python 3.12.3 (materials target 3.13, runs unchanged)
#   pydantic 2.13.4, pandas 3.0.2, matplotlib 3.10.8
# On the cohort stack (pydantic 2.13.4, pandas 3.0.2) the behavior is identical.
#
# Install with plain pip into a fresh virtual environment:
#   python -m venv .venv && source .venv/bin/activate
#   pip install -r requirements.txt
#
# ---------------------------------------------------------------------------
# Core dependencies (required for the full offline demo)
# ---------------------------------------------------------------------------
pydantic
pandas
matplotlib

# The generation step runs offline by default against a deterministic scripted
# model. Set BACKEND_MODE to lmstudio or ollama to call a real local model, which
# needs the OpenAI client (both local backends speak the OpenAI compatible API).
#   openai            verified against 2.46.0

# Not required: the original notebook used tiktoken for token counting. It is
# dropped here. The demo uses a transparent character-based token estimate, which
# is the right call for a local Gemma model anyway, since tiktoken does not know
# that tokenizer.
