# Week 4 Demo 02: Grounded Answers You Can Trust
# The core demo (Parts 0 through 7) runs on scikit-learn and numpy only.
# No GPU, no model download, no network. It starts instantly on the cohort Macs.
#
# Verified by running the instructor notebook end to end in the build environment on:
#   Python 3.12.3 (materials target 3.13, runs unchanged)
#   numpy 2.4.4, pandas 3.0.2, scikit-learn 1.8.0, matplotlib 3.10.8
# On the cohort stack (numpy 2.4.x, pandas 3.0.2) the behavior is the same. Exact
# similarity decimals can shift a little on a different scikit-learn build, but the
# pattern holds: covered questions score well above the abstain threshold and off
# topic questions score 0.0.
#
# Install with plain pip into a fresh virtual environment:
#   python -m venv .venv && source .venv/bin/activate
#   pip install -r requirements.txt
#
# ---------------------------------------------------------------------------
# Core dependencies (required for Parts 0 through 7)
# ---------------------------------------------------------------------------
scikit-learn
numpy
pandas
matplotlib
