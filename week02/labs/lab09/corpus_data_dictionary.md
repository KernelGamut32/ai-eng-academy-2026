## 1. Source corpus — `data/corpus_llm.csv` (1,014 rows)

An LLM-native corpus (help articles, policies, release notes, FAQs) — metadata-rich for
RAG filtering, and deliberately messy.

| Column | Type | Meaning |
|---|---|---|
| `doc_id` | str | document id (`DOC-0001` …; planted `DOC-DUP-*`, `DOC-EMPTY-*`) |
| `type` | str | `help_article` \| `policy` \| `release_note` \| `faq` |
| `title` | str | short title |
| `section` | str | `Overview` \| `Setup` \| `Troubleshooting` \| `FAQ` |
| `body_text` | str | the document text (a few are empty by design) |
| `tags` | str | comma-joined tags (RAG filter facets) |
| `source_url` | str | provenance URL (`https://example.local/…`) |
| `created_at` / `updated_at` | str (`YYYY-MM-DD`) | timestamps; `updated_at` breaks dedupe ties |
| `language` | str | `en` (×3) \| `de` \| `fr` — mostly English |
| `confidentiality` | str | `public` \| `internal` — the governance label |

**Planted mess (so the pipeline has real work):**
- **9 exact-content duplicates** (`DOC-DUP-00…08`) — identical text to the canonical
  `DOC-0001` under new `doc_id`s. They collapse *only* if you dedupe on **content**, not id.
- **5 empty bodies** (`DOC-EMPTY-00…04`) — dropped by the min-length filter.

> **pandas 3.0 note:** `read_csv` returns the **`str`** dtype for text columns (not
> `object`). `.str` accessors work as normal; blanks may read back as `""` or `NaN`, so
> guard both when counting "empty."

## 3. Output — RAG chunk JSONL (`artifacts/jsonl/rag_chunks.jsonl`, 546 lines)

One line per chunk:
```json
{"doc_id": "...", "chunk_id": "DOC-0001-0000", "text": "...",
 "metadata": {"title": "...", "section": "...", "tags": "...", "source_url": "...",
              "language": "en", "confidentiality": "public", "schema_version": "rag-chunk-v1"}}
```
`chunk_id` = `f"{doc_id}-{j:04d}"`. Provenance (`source_url`, `title`, `schema_version`)
travels with every chunk so a retrieved passage is traceable.

## 5. Currency fixes over the source lab (verified against the stack)

| Source | Problem | Resolution |
|---|---|---|
| `@app.on_event("startup")` | **deprecated** in current FastAPI/Starlette | modern **`lifespan`** context manager |
| module-level `global DF` | discouraged; awkward to test | state on **`app.state.df`** |
| `TestClient` for ingest | Starlette is mid-migrating its `httpx` backend (`httpx2` warning) | **background `uvicorn` + `requests`** (production-shaped, matches Day-4 pattern) |
| `DF = pd.read_csv('../data/...')` | breaks unless CWD is `tools/` | resolve path with `pathlib` relative to the file |
| `str.contains(q, ...)` | default `regex=True` → user input treated as regex | pass **`regex=False`** for literal search |
| `%pip install requests orjson` mid-notebook | non-reproducible | declared in `requirements.txt` |
| prereqs list `regex` | code only uses stdlib `re` | dropped `regex` |
| `split_chunks(max_chars=900)` on ~700-char bodies | overlap path never runs | **300/60** window so chunks actually split (exercises overlap) |
| dedupe temptation on `doc_id` | misses duplicate *content* | **SHA-1 content signature** on normalized title+body |
