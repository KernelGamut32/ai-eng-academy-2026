# `orders_clean.parquet` — Data Dictionary

**Cordwell Home & Hardware · Week 1 Capstone**
Companion to `data/processed/orders_clean.parquet`, produced by
`run_cleaning_pipeline`. Synthetic, clearly-fictional data.

One row = one **order line** (a single product on a single order). The clean file
contains **one row per `order_id`** (deduplicated) with all nulls resolved, dtypes
enforced, and values validated against `CLEAN_SCHEMA`.

| Column | Type | Nullable | Description & cleaning caveats |
|---|---|---|---|
| `order_id` | string | No | Unique order-line identifier (format `ORD-########`). Rows with a missing key were **dropped**; duplicate keys were **deduplicated**, keeping the most recently `updated_at` record. Enforced **unique**. |
| `order_date` | datetime64[ns, UTC] | No | Order date, parsed from `YYYY-MM-DD` with an explicit format and localized to **UTC**. |
| `store_id` | int64 | No | Store identifier (100–149). |
| `store_region` | string | No | Canonical U.S. region: one of `Southeast`, `Northeast`, `Midwest`, `West`, `Southwest`, or `Unknown`. Alias spellings (`se`, `South East`, `MW`, …) were mapped to canonical form; **nulls filled with `"Unknown"`** (missingness preserved as a category). |
| `product_sku` | string | No | Stock-keeping unit (format `SKU-#####`). |
| `product_category` | string | No | Canonical department: one of `Power Tools`, `Hand Tools`, `Lumber`, `Plumbing`, `Electrical`, `Paint`, `Flooring`, `Hardware`, `Garden`, `Appliances`. Case/whitespace normalized then mapped to canonical Title case. |
| `product_name` | string | No | Product description, **lower-cased and whitespace-normalized** (leading/trailing stripped, internal runs collapsed) for consistent grouping. |
| `quantity` | int64 | No | Units ordered. **Clipped to `[1, 500]`**; see `quantity_capped`. Nulls were **median-imputed** before capping. |
| `quantity_capped` | bool | No | `True` if the raw `quantity` fell outside `[1, 500]` and was clipped. |
| `unit_price` | float64 | No | Price per unit in USD. **Clipped to `[0, 10000]`**; see `unit_price_capped`. Nulls were **median-imputed**. Negative raw prices (data errors) were clipped to `0`. |
| `unit_price_capped` | bool | No | `True` if the raw `unit_price` fell outside `[0, 10000]` and was clipped. |
| `discount_pct` | float64 | No | Line discount percentage. **Clipped to `[0, 100]`**. Missing discounts were filled with `0.0` (a missing discount means no discount). |
| `channel` | string | No | Canonical sales channel: one of `In-Store`, `Online`, `Pro-Desk`, or `Unknown`. Alias spellings (`web`, `in store`, `pro desk`, …) were mapped; **nulls filled with `"Unknown"`**. |

**Dropped from the raw file:** `updated_at` — used only to choose the surviving row
during deduplication, then discarded (not part of the clean contract).

**Provenance:** generated by `scripts/generate_raw_data.py` (seeded, reproducible),
cleaned by `cordwell.data.cleaning.run_cleaning_pipeline`, and validated by
`cordwell.data.cleaning.CLEAN_SCHEMA` before writing.
